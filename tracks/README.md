# Tracks

Each track is one worked example, one checker, and one set of checks.

| Track | What it covers | Status |
|---|---|---|
| [Track 1](track-1-flexure-example.md) | Flexure checks for one concrete beam with carbon fiber fabric, ACI 440.2R-17 Chapter 10 | Result recorded in results/track-1-flexure/. Publisher confirmation of the strengthened strength stays open. |

Later tracks, in the order Shahid set:

- Track 2: the strengthening limit and fire case in full, ACI 440.2R-17 Section 9.2 and Chapter 9. Track 1 already carries the worked example's own limit check, which follows ACI 562-16 Section 5.5.2. Track 2 is the guide's fuller treatment, not a repeat of that check.
- Track 3: shear strengthening with fabric wraps.
- Track 4: a masonry wall case, once a published worked example is found.

A later track opens only when Track 1 has a checker that matches its
example. One beam, checked well, comes before four beams checked loosely.
